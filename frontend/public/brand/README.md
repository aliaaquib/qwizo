# Qwizo Brand Asset Handoff

## Approved direction
Use the Arc + Qwizo wordmark as the approved Qwizo identity.

## Colors
- Qwizo Lime: #DFF45B
- Charcoal: #0F172A
- Sky: #E7F0FF
- White: #FFFFFF

## Typography
The supplied SVG wordmark uses a bold geometric sans treatment based on Inter.
For editable UI text, use the project's chosen Qwizo typeface consistently.

## Asset usage
- `qwizo-logo-light.svg` — primary logo on light backgrounds
- `qwizo-logo-dark.svg` — primary logo on charcoal/dark backgrounds
- `qwizo-logo-monochrome.svg` — one-color black
- `qwizo-logo-reverse.svg` — one-color white/reverse
- `qwizo-logo-stacked.svg` — compact/stacked placement
- `qwizo-mark.svg` — standalone Arc mark
- `qwizo-mark-dark.svg` — Arc mark on dark background
- `qwizo-mark-monochrome.svg` — black mark
- `qwizo-mark-reverse.svg` — white mark
- `favicon*.png` / `favicon.svg` — browser favicon
- `qwizo-app-icon*.png` / `.svg` — app icon

## Important
Do not redesign, rotate, stretch, recolor, or add effects to the approved Arc.
Use the SVG assets directly rather than treating a screenshot as the logo.
